# Wealth Life Simulator 产品需求文档（PRODUCT）

版本：v1.0 规划稿 ｜ 日期：2026-11-19 ｜ 状态：待开发

## 1. 产品定位

一句话：**输入你的现在，观看你的未来，改变你的决定，体验另一种人生。**

这是一个以「趣味性、互动性、沉浸感、重复游玩」为第一目标的财富人生模拟游戏。它不是理财计算器：用户不是来得到精确理财建议的，而是来体验一条有起伏、有意外、有遗憾或有惊喜的人生财富轨迹，并且愿意立刻再玩一次。

约束底线：底层财务计算必须逻辑自洽（名义/实际口径一致、现金流守恒、种子可复现），戏剧性来自事件与市场波动，不来自错误的算术。

### 1.1 成功标准（按优先级）

1. 用户在 30 秒内完成输入并看到第一年财富开始变化。
2. 用户在模拟过程中主动期待下一个事件（事件间隔有节奏感，不平淡也不轰炸）。
3. 一局结束（约 2–4 分钟）后，用户愿意点击「换一种人生」再来一局。
4. 用户愿意把结局链接发给朋友（分享链接可直接重播同一人生）。
5. 财务口径经得起推敲：同一种子同一选择结果完全一致，通胀口径无矛盾。

### 1.2 非目标（v1 明确不做）

- 用户账户、登录、后端数据库、支付、正式部署、社交社区。
- 真实投资建议、税务精算、多币种、逐月/逐日模拟。
- 复杂表单（房贷明细、保险配置、多账户资产管理）。

## 2. 目标用户与使用场景

- 25–40 岁、对「财富自由 / FIRE」话题感兴趣的互联网用户。
- 场景：社交媒体看到分享链接 → 打开 → 30 秒输入 → 玩一局 → 看到结局 → 再玩或分享。
- 设备：桌面优先设计，移动端必须可完整游玩（第二优先级，但布局从第一天起响应式）。

## 3. 核心游戏循环

```
输入现在 → 观看财富逐年增长 → 关键年份弹出人生事件 → 做出选择
   ↑                                                    ↓
   └──── 换一种人生（改输入/改选择/换种子） ←── 人生结局 ←──┘
```

一局时长目标：2–4 分钟。默认每年播放约 1.1 秒，事件暂停时不计入。以 30 岁开始、90 岁终点计，60 年 ≈ 66 秒纯播放 + 8–14 次事件决策（每次 5–15 秒）。

## 4. 页面与视图规划

单页应用，四个视图（开局/模拟/结局/分享接收）由状态机切换（不引入路由库），分享通过 URL hash 携带重播数据。

| 视图 | 名称 | 职责 |
|---|---|---|
| `setup` | 开局页 | 品牌第一眼 + 快速输入 + 开启按钮 |
| `simulating` | 模拟页 | 沉浸式逐年播放、事件决策、暂停/加速 |
| `ending` | 结局页 | 人生结局展示、关键数据、重玩与分享 |
| `shared` | 分享接收页 | 平行人生来信 + 观看重播 / 同起点自己玩 |

### 4.1 开局页（setup）

视觉目标：第一眼高级、沉浸、有轻度游戏感。深色背景，中央一张玻璃质感输入卡片，背景有极缓慢流动的财富曲线光效（纯装饰，不干扰可读性）。

文案极简：只有产品名、一句 slogan、输入项和按钮。不放功能介绍、流程说明、统计数字。

输入项（全部必填，共 4 项 + 1 个目标模式开关）：

| 字段 | 控件 | 默认值 | 校验 |
|---|---|---|---|
| 当前年龄 | 数字输入 + 滑杆 | 28 | 18–70 整数 |
| 当前可投资资产 | 金额输入（¥） | 200,000 | ≥ 0，上限 1e12 |
| 年税后收入 | 金额输入（¥） | 200,000 | ≥ 0，上限 1e10 |
| 年生活支出 | 金额输入（¥） | 120,000 | > 0，上限 1e10 |
| 财富自由目标 | 二选一：「自动（支出 × 25）」/「手动输入」 | 自动 | 手动时 > 当前支出 × 5 |

交互细节：
- 金额输入失焦后格式化千分位，下方小字实时显示换算（如「≈ 20 万」）；负数、非数字与超限输入保留原文并阻止开局，不吞掉符号或截断成另一个合法金额。
- 选择「自动目标」时实时显示计算出的目标金额（按当前支出 × 25）。
- 资产为 0 允许（白手起家剧本）；支出 > 收入允许（吃老本剧本），不阻断，只在按钮下方显示一行中性提示「支出高于收入，这会是艰难的一局」。
- 主按钮：「开启我的财富人生」。点击后立即进入模拟页并开始播放，无加载页、无二次确认。
- 提供「随机人生」次级按钮：随机生成一组合理输入，降低首次输入成本。
- 若 URL hash 携带重播数据：进入独立的分享接收页（「你收到了一段来自另一个平行人生的故事」+ 起点摘要），提供「观看 TA 的人生」与「相同起点，我来试试」两个入口；hash 非法时给出中性提示并保留正常开局表单，不白屏。

### 4.2 模拟页（simulating）

布局（桌面）：
- 顶部 HUD：当前年份（如 2038）、当前年龄、距离目标进度条；右侧暂停/继续、速度（1×/2×/4×）、重新开始。
- 屏幕中央：超大字号资产数字（滚动动画），下方一行小字显示实际购买力口径数值与「距财富自由还差 X」。
- 下半屏：逐年延伸的财富曲线（ECharts），含目标线（虚线）；曲线随年份平滑生长。
- 事件发生时：播放暂停，曲线停止，中央弹出事件卡片（背景压暗 + 轻微模糊）。

事件卡片规格：
- 结构：事件插画/图标区（v1 用高质量渐变图形 + emoji 级图标，不用廉价贴图）、标题（≤ 12 字）、一段情境描述（≤ 60 字）、2–3 个选项按钮。
- 每个选项按钮显示：选项文案 + 一行可感知的代价/收益提示（如「-¥300,000，换取年收入 +15%」）。数值提示必须与引擎实际效果一致。
- 选择后：卡片收起，显示一条简短结果反馈（1 行字 + 数字变化飘字），播放继续。
- 事件期间用户可关闭声音（v1 无声音，预留）、可点击「回顾」查看已发生事件时间线（侧边抽屉）。

播放与暂停：
- 自动逐年推进；用户可随时暂停/继续，暂停时曲线与数字静止。后台恢复或长帧不追赶多个年份；打开人生回顾时暂停，关闭后由用户继续。
- 事件、人生回顾、回溯面板使用模态焦点与焦点恢复；回顾/回溯可按 Escape 关闭，待决事件不能跳过。结局曲线提供可键盘展开的逐年数据与事件入口。
- 页面加载失败显示「重新加载 / 重新开局」，暂停播放并保留可用检查点，不白屏；剪贴板失败显示可手动复制的链接，不假报成功。
- 事件强制暂停，必须做出选择才继续（不允许跳过事件；v1 每个事件都有默认中性选项兜底）。
- 用户中途刷新页面：从 hash/本地存储恢复 inputs + seed + 已做选择，重算到当前年份后继续（见 ARCHITECTURE 重播机制）。

财富曲线更新规则：
- 事件的一次性现金影响体现在事件发生当年的曲线点上；持续性影响（收入/支出/收益率修正）从次年开始改变曲线斜率。
- 曲线只追加不重绘历史（历史是已发生的事实）；重播/改选择时整条曲线重建。

### 4.3 结局页（ending）

触发条件（详见 SIMULATION）：
1. **财富自由**：资产 ≥ 当年目标线 → 立即进入结局（庆祝基调）。
2. **走到终点**：到达 90 岁未达成目标 → 按最终资产与目标比值分档结局。
3. **财务崩溃**：净资产为负且触发破产规则 → 提前结局（遗憾但不羞辱用户的基调）。
4. **开局即自由**：初始资产已达标 → 隐藏彩蛋结局（空历史，趣味基调）。

结局页内容：
- 视觉中心提问「你的人生最终走向了哪里？」+ 结局称号（大字，如「传奇提前退休」「稳健的长跑者」「差一步的赶路人」「被生活暴击的人」）+ 达成年份/年龄。
- 一段人生叙事文案（开场 + 关键转折点 + 2–3 句真实事件故事 + 收尾；只引用本局真实发生的事件与选择，不虚构、不做未经计算的反事实比较）。
- 关键数字（最多 4 个）：最终资产（附实际购买力小字）、目标、经历年数、人生事件数。
- 完整财富曲线（资产线 + 目标虚线 + 事件标记点按现金影响正负着色 + 终点节点；悬停/点击回看该年抉择）。
- 操作（按视觉权重排序）：
  1. 「换一种人生」：同输入、新种子直接开局。
  2. 「回到过去，改变命运」：列出本局所有事件选择，从任意一个事件处改选（同种子截断重播，分歧点之前不变）。
  3. 「重看这一生」：同种子同选择逐年自动重播，事件处展示原选择。
  4. 「分享我的人生」：复制重播链接（URL hash 编码 inputs + seed + 选择日志）+ 复制成功反馈。
  5. 「修改初始信息」：回到开局页，保留上次输入。（「随机人生」入口保留在开局页。）

分享链接打开后：对方可直接「观看这条人生」（自动重播，事件处展示原玩家的选择）或「用同样开局玩自己的人生」（同输入新种子）。

### 4.4 平行宇宙（P4-B）

- 结局故事、资产与原有操作优先；其后增加可主动展开的卡片「如果人生可以重来 300 次……」，副标题「同样的起点，不同的市场走势，会通向怎样的未来？」与「看看我的平行宇宙」。收起时不计算。
- 展开显示青绿 p10–p90 区间、中位线、暖金色真实人生与基线目标虚线；开局与首年年末分为两个点，真实曲线在最后结算年终止。默认聚焦实际人生年限（短人生展示最多前10年基线，实际曲线不延长），可切换完整年限。Tooltip 与可键盘操作的年份滑杆显示同年人民币金额。
- 40/45/50/55/60 岁前累计达成使用 firstFireDistribution 中 age < 门槛的 count 求和；只显示 startAge < 门槛 ≤ endAge 的门槛。以路径数为主、百分比为辅，不突出终点 100%。无适用门槛时展示终点前达成路径数。
- 策略按钮进取/平衡/保守切换真实配对计算结果、累计条与成功者中位年龄，不推荐策略。手机横向三按钮，解释只显示当前策略，不塞三列分析卡片。
- 相对比较使用 compareWithParallelLives：注明结束年/开局，在 n 条路径中超过 belowCount 条；平局不算超过。参数不兼容时明确不能比较。
- 始终标注「无人生事件、持续工作并投资的模型基线；区间并非保证，也不是投资建议。你的真实人生包含事件。」破产后数学续算、FIRE后继续工作口径提供简短可展开说明。
- 资产主数字达到亿级时使用人民币「亿／万亿」单位，完整金额保留于 title/无障碍名称；图表详情仍显示完整人民币，避免手机拆断长数字。
- 按需加载图表与 Worker；首次只算平衡，随后独立任务算进取/保守。收起、退出取消未完成任务；同一局重新展开复用完成结果，重播/新局隔离缓存。支持 reduced-motion。

## 5. 事件体验要求

- 每局事件数目标 8–14 次；间隔节奏：前期（前 10 年）较密建立代入感，中期平稳，后期有 1–2 次高冲击事件。
- 事件必须有故事性：具体情境（「朋友拉你合伙开咖啡店」），不是抽象参数（「投资机会：±20%」）。
- 每个选项的影响必须真实进入引擎并在后续曲线可见；禁止纯装饰选项。
- 选项无绝对对错：高收益伴随高风险或代价，稳健选项有机会成本。
- 事件池分类与具体清单见 SIMULATION.md 第 5 节。

## 6. 优先级矩阵

| 级别 | 内容 |
|---|---|
| P0（必须惊艳） | 开局页视觉、30 秒开局、逐年财富动画、事件卡片质感、结局叙事、再玩动机 |
| P1（必须正确） | 财务口径自洽、种子可复现、事件与引擎解耦、暂停/恢复、未达成目标的结局处理 |
| P2（第二优先） | 蒙特卡洛多路径（成功率与分位带）、策略比较视图、移动端打磨、结果分享 |
| 不做 | 账户、后端、支付、部署、社区 |

## 7. 验收用的体验指标（开发自测）

- 冷启动到第一年数字开始变化 ≤ 3 秒（本地开发环境）。
- 输入页从打开到可点击开始 ≤ 30 秒（默认值已填好，只需微调）。
- 一局默认速度总时长 2–4 分钟。
- 分享v2在接收前验证规则版本、终局及分单位规范化轨迹；不同浏览器要么复现同一可校验人生，要么明确拒绝并返回开局。旧v1提示重新分享，不作为已验证人生播放。
- 任意一局中，名义资产、实际购买力、目标线三者口径抽查无矛盾。
