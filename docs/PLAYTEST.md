# 财富人生模拟器 · 小范围试玩说明

建议留出 10–15 分钟。这是人生模拟游戏，不是理财建议；请用示例数字，不必提供真实财务信息。

## 怎么开始

本轮由组织者在已准备好的电脑上带领试玩，可现场操作或屏幕共享。使用桌面 Chrome，打开 http://127.0.0.1:4176/ 。这个地址只在运行预览的电脑上有效，不能直接发给异地朋友当作在线网站；当前没有部署公开站点。

1. 第一次可以不改数字，直接点「开启我的财富人生」。收入和生活支出填的是**一年**的金额，不是月薪。
2. 看资产数字和曲线变化。想看快一点选 2× 或 4×，想停下来选「暂停」。
3. 人生事件出现时，先读情境和选项下方的代价，再按自己的直觉选；没有必须答对的答案。
4. 到结局后看看称号和故事。向下滚动，点「看看我的平行宇宙」，试试「进取／平衡／保守」；这些是模型对比，不是投资推荐。
5. 点「回到过去，改变命运」，挑一个事件换个选择；看看结果如何变化。
6. 点「分享我的人生」，在同一电脑的另一个浏览器窗口打开完整链接，再点「观看 TA 的人生」。观看时会自动沿用原选择。若复制失败，手动复制页面提供的链接。
7. 想重新体验随机故事，点「换一种人生」；想改数字，点「修改初始信息」。

## 试玩前知道这几件事

- 进度只保存在当前浏览器、当前地址下；刷新通常可以恢复。换浏览器、换端口、清理网站数据或结束隐私窗口后，不保证还能找到原进度。没有账户或云端备份；开启新人生会替换当前本地进度。
- 分享链接包含输入数字和选择记录，不是加密秘密。不要公开真实财务数据；链接要完整复制。
- Safari 和真实手机尚未完成兼容性验收。若收到「无法复现」提示，不表示你操作错了：不要期待它继续播放另一种结果，可改用发送方的浏览器或直接正常开局。旧版链接需要发送方用新版重新分享。
- 平行宇宙和结局都不预测真实人生，也不承诺收益。

## 帮我们回答四个问题

1. 首页哪里让你犹豫，不知道填什么或点什么？
2. 哪个事件最想认真选择？选项有没有让你误解？
3. 结局像不像你的这段故事？你愿意再玩一次吗？
4. 有没有点不动、看不清、卡住或分享打不开的地方？

遇到问题时，请记录浏览器、设备、当时点了什么，附一张截图；涉及真实数字的链接先不要公开发送。
