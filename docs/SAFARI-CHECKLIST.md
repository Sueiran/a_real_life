- [ ] **首页与一局模拟**：Safari 打开首页，默认输入直接开局。资产数字、曲线、年份能推进；暂停后停止，继续后恢复，2×／4×可用。
- [ ] **事件与选择**：事件弹出时播放停止，标题与选项可读可点；选择后继续，无遮罩残留或必须刷新才能继续。
- [ ] **事件刷新**：待选事件出现后刷新；仍是同一事件、相同年份和选项。作出选择并暂停，记下年份，再刷新，仍停在该位置。
- [ ] **结局与重玩**：完成一次模拟，记录称号、年份、年龄、最终资产；故事可读，完整曲线可见。「回到过去，改变命运」能改选，「重看这一生」能自动播放。
- [ ] **平行宇宙**：展开成功，依次切换进取／平衡／保守，图表和文字都有结果；收起再展开仍可用，不一直显示计算中。
- [ ] **Chrome → Safari 分享**：Chrome 完成一局，记录称号、年份、年龄、最终资产，点击分享并将完整链接粘贴到 Safari 地址栏。
  - [ ] 若出现「观看 TA 的人生」，播放至结局，逐项比较上述记录；事件选择应自动沿用。能在两端再次复制链接时，还可交给开发者核对结局字段和轨迹指纹。
  - [ ] 若出现「无法复现」等拒绝提示，记录文字和链接：必须不出现可观看入口，不能悄悄播放另一条人生，仍能正常开局。**明确拒绝不是互通成功，应单独记为安全拒绝。**
- [ ] **固定拒绝用例**：把一个 Chrome 新分享链接的 `#r=` 及后面内容换为 `#r=invalid` 后打开；应提示链接无法读取并保留正常开局，不白屏。不要改原始链接记录。
- [ ] **Safari 复制**：Safari 结局点击分享，有明确成功反馈；若系统拒绝剪贴板，应出现可手动选择、复制的完整链接，不能假报已复制。正常生成的链接再在 Chrome 打开，接受则比较结局，拒绝则记录原因。
- [ ] **本地存储隔离**：先在 Safari 暂停自己的一局并记下年份；在新标签打开 Chrome 的分享并观看。关闭分享标签，回到原标签刷新，自己的进度仍在。最后完成自己的结局，刷新后仍能恢复结局。
- [ ] **窗口缩小**：把 Safari 窗口缩小，检查主要文字、事件按钮、分享链接和三策略能读能操作。此项不等于真实手机测试。
