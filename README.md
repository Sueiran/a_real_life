# 财富人生模拟器

输入一组当前财务状况，体验财富随时间变化、人生事件抉择和不同结局。项目是纯前端模拟游戏，不提供投资建议，也没有账户或云端存档。

## 本地运行

需要安装 Node.js 和 npm。在项目目录执行：

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可开始。结束开发服务器时，在终端按 `Ctrl+C`。

## 怎么玩

1. 在开局页填写年龄、当前可投资资产、年税后收入和年生活支出；也可以直接使用默认值或点「随机人生」。收入和支出按**每年**填写。
2. 点「开启我的财富人生」，模拟会自动逐年播放。可暂停，或切换 1×、2×、4×速度。
3. 遇到人生事件时，选择一个选项后继续。可打开人生回顾查看已发生的事件。
4. 结局页可以查看人生故事和财富曲线、展开「平行宇宙」比较模型路径、回到某个事件改选、重看这一生，或分享人生。
5. 分享链接可重播这条人生；选择「相同起点，我来试试」则用相同输入开启一段新人生。

## 存档与分享

当前进度保存在本机浏览器中，没有账户或云端备份。分享链接包含模拟输入、随机种子和选择记录；任何拿到链接的人都能看到这些内容。请使用示例数字，不要把真实财务信息放入公开分享链接。

这个仓库提供源代码，不代表网站已经部署上线。要让别人在线访问，需要另行部署；本项目目前没有配置公开网站。

## 开发命令

```bash
npm run dev       # 启动本地开发服务器
npm run build     # 类型检查并构建生产文件
npm run test      # 运行自动化测试
npm run verify    # 核对固定种子的模拟结果
npm run verify:mc # 核对蒙特卡洛模拟结果
```

产品、模拟规则和结构说明见 [`docs/PRODUCT.md`](docs/PRODUCT.md)、[`docs/SIMULATION.md`](docs/SIMULATION.md) 和 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)。内部试玩流程见 [`docs/PLAYTEST.md`](docs/PLAYTEST.md)。
